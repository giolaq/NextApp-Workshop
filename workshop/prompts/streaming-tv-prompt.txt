Work in the current React Native multi-TV monorepo. Preserve unrelated user
changes and do not use another branch as a reference.

Read the existing README, workshop instructions, and shared app code before
editing. Follow the workshop's existing patterns, use the same simple language,
and keep the result easy for an attendee to understand.

Transform the existing workshop home screen into a simple streaming-style TV
application inspired by Amazon's react-native-multi-tv-app-sample, without
copying its full navigation architecture.

Objective

Create a small end-to-end TV experience consisting of:

1. A 10-foot browse screen.
2. One horizontal content shelf.
3. A hero area updated by focus.
4. A basic cross-platform video player.

Keep the implementation simple and primarily inside packages/shared.

Browse screen

- Replace the workshop tile layout with a streaming-style home screen.
- Add a static content data file containing four items.
- Each item must contain:
  - id
  - title
  - description
  - poster image URL
  - hero image URL
  - video URL
- Use stable HTTPS clear-content MP4 URLs for the videos.
- Do not use HLS, DASH, DRM-protected, or live streams in this iteration. Those
  require MSE mode and a JavaScript player such as Shaka Player, hls.js, or
  dash.js on Vega.
- Do not fetch a remote catalog.

- Display a large hero image across the upper portion of the screen.
- Add a dark gradient or readable scrim over the hero.
- Show the focused item's title and a description limited to three lines.
- Add one horizontal row titled “Featured”.
- Render four landscape content cards.
- Focusing a card must immediately update the hero content.
- Selecting a card must open its video.

10-foot UI

- Continue using the existing 1920x1080 scaling utilities.
- Add reusable title-safe and action-safe spacing constants.
- Keep text readable from a TV viewing distance:
  - Hero title approximately 56–64 design pixels.
  - Description approximately 26–30 design pixels.
  - Shelf title approximately 36–40 design pixels.
- Keep important content at least 5% away from screen edges.
- Avoid small labels, crowded layouts, or mobile-style controls.

TV focus

- Preserve D-pad navigation and preferred focus on the first card.
- Use the existing React Native focus events; do not add a spatial-navigation
  dependency for a single row.
- Focused cards must:
  - Scale to approximately 1.08.
  - Show a visible orange border or glow.
  - Remain unclipped.
- Add accessibilityRole, accessibilityLabel, and stable testID values.
- Remember the selected card when returning from playback where practical.

Video player

- Selecting a card opens a full-screen player without introducing a complete
  navigation framework. A small browse/player state machine in HomeScreen is
  sufficient.
- Use a black full-screen background.
- Autoplay the selected video.
- Show loading and clear playback-error states.
- Add a controls overlay containing:
  - Play/Pause
  - Exit
- Show controls when playback starts or the user interacts.
- Automatically hide controls after five seconds.
- Back must stop playback and return to the browse screen.
- Clean up timers, listeners, surfaces, and player instances on unmount.

Platform implementation

- Create a shared player interface.
- Use react-native-video for Expo TV targets.
- Create a .kepler.tsx player implementation for Vega URL-mode playback using
  VideoPlayer and KeplerVideoSurfaceView from
  @amazon-devices/react-native-w3cmedia.
- Initialize the VideoPlayer after the surface is created, attach the surface
  handle, enable autoplay, assign the clear MP4 URL, and clear the surface
  handle and deinitialize during cleanup.
- Add only dependencies genuinely required by each workspace.
- Verify compatible versions against the React Native version used by each
  workspace rather than copying versions blindly.
- Provide a simple web fallback if native playback is unavailable.
- Do not implement captions, seeking, media sessions, or hardware media-key
  integration in this iteration.

Vega media configuration

- Update packages/vega/babel.config.js for W3C Media without removing the
  existing Kepler module resolver preset:
  - Set useTransformReactJSXExperimental: true on
    module:metro-react-native-babel-preset.
  - Add @babel/plugin-transform-react-jsx with runtime: automatic.
  - Declare @babel/plugin-transform-react-jsx in packages/vega if it is not
    already a direct dependency.
- Add the W3C Media setup entries to packages/vega/manifest.toml under [wants]:
  - com.amazon.mediametrics.service
  - com.amazon.devconf.privilege.accessibility
  - com.amazon.mediabuffer.service
  - com.amazon.mediatransform.service
  - com.amazon.audio.stream
  - com.amazon.audio.control
  - com.amazon.media.server
  - com.amazon.media.playersession.service
- Preserve the existing manifest package, component, and needs declarations.

Testing

Add meaningful tests verifying:

- The hero and four Featured cards render.
- The first card has preferred TV focus.
- Focusing another card updates the hero title and description.
- Selecting a card opens the player.
- Play/Pause changes state.
- Exit returns to the browse screen.
- Loading and error states render.
- Platform video modules are represented by lightweight Jest mocks.

Validation

- Install dependencies using the Yarn version pinned by the repository.
- Do not modify yarn.lock unless dependencies genuinely change.
- Run the shared TypeScript check and tests.
- Run Vega tests with Watchman disabled.
- Run Vega lint.
- Run Expo TV lint and TypeScript validation.
- Run git diff --check.
- Build the Vega debug packages.
- Launch the Vega build on the Vega Virtual Device or a connected physical Vega
  device. Validate the interaction manually or with Appium:
  - Home loads with the first card focused.
  - Moving right updates the hero.
  - Selecting a card opens the player.
  - Play/Pause and Exit are usable.
  - Returning restores a usable focus position.

Report all changed files, dependencies added, checks passed, Vega build
artifacts, device or Appium validation evidence, and remaining warnings.
